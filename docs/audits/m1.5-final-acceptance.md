## Non-blocking limitations

- FS-002 HIGH is an exposure judgment; invocation of the replaced root SUID
  binary is not observed.
- ACLs, privileged consumers, sudoers, service environments, capabilities,
  systemd, cron and container/namespace analysis remain out of scope.
- Group semantics are conventional; local daemon/socket configuration can
  differ.
- Sysctl/MAC observations describe the shared Docker kernel.
- arm64 was compiled, not executed in the lab.
- Image manifest identity changes across rebuilds; only the base digest is
  pinned.
- `internal/app` unit coverage is 22.9%; end-to-end orchestration is covered by
  the lab.
- The repository has no commit or release.

None of these is a critical correctness or safety defect, and each is stated in
the finding text or documentation rather than hidden.
