## Preliminary audit targets (confirmed by reading code)

1. `NULQ-FS-003` marks a writable PATH directory `HIGH` without any observed
   privileged consumer; an empty PATH element is also `HIGH`.
2. `NULQ-FS-001` assigns `MEDIUM` for a non-standard location and for non-root
   ownership, neither of which establishes exposure.
3. `NULQ-FS-002` escalates to `HIGH` solely because a world-writable directory
   is on PATH, and its containment check matches files in nested
   subdirectories by string prefix.
4. `NULQ-SYS-002` resets its enforcement flag after a permissive SELinux
   finding, so an enforcing AppArmor module is ignored.
5. Coverage does not report excluded mount points, timed-out or cancelled
   operations; it only exposes failures as free text.
6. The laboratory validator does not detect duplicate findings or dangling
   evidence references.

These are audited and corrected in the M1.5 correction pass; the final report
contains the rule matrix and evidence.
